This tutorial demonstrates how to use different cache encodings with the .NET Hot Rod client.

== Prerequisites

* A running Infinispan server.
* .NET 10 or later.

== Running the Example

[source,shell]
----
dotnet run --project encoding
----

== Code Walkthrough

=== Text Cache

Create a cache with `text/plain` encoding.
The builder infers `StringMarshaller` from the `string` type parameter.

[source,csharp]
----
var textCache = client.NewCache<string>("textCache")
    .WithEncoding(MediaType.PlainText)
    .Build();

await textCache.Put("greeting", "Hello, Infinispan!");
var val = await textCache.Get("greeting");
----

=== JSON Cache

Create a cache with `application/json` encoding and store JSON documents.
Keys must be valid JSON values (e.g. a quoted string).

[source,csharp]
----
var jsonCache = client.NewCache<string>("jsonCache")
    .WithEncoding(MediaType.JSON)
    .Build();

await jsonCache.Put("\"name\"", "{\"project\": \"infinispan\"}");
----

== Expected Output

== Cache with text/plain encoding ==

== Cache with application/json encoding ==
