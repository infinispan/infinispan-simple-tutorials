This tutorial demonstrates how to register a cache event listener that receives notifications when entries are created, modified, or removed.

== Prerequisites

* A running Infinispan server.
* .NET 10 or later.

== Running the Example

[source,shell]
----
dotnet run --project listeners
----

== Code Walkthrough

=== Implementing a Listener

Implement the `IClientListener` interface to handle cache events.

[source,csharp]
----
class EventPrinter : IClientListener
{
    public string ListenerID { get; set; }

    public void OnEvent(Event e)
    {
        var key = Encoding.UTF8.GetString(e.Key);
        Console.WriteLine($"{e.Type} {key}");
    }

    public void OnError(Exception ex) { }
}
----

=== Registering and Removing

Use `AddListener` to start receiving events and `RemoveListener` to stop.

[source,csharp]
----
await cache.AddListener(listener);
// ... perform operations ...
await cache.RemoveListener(listener);
----
