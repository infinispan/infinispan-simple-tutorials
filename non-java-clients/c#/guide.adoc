:mode: remote

TIP: The source code for these tutorials is available on link:https://github.com/infinispan/infinispan-simple-tutorials/tree/main/{source-dir}[GitHub].

These tutorials demonstrate how to use the link:https://github.com/infinispan/Infinispan.Hotrod[Infinispan .NET Hot Rod client] to connect to an Infinispan Server and perform common operations.

== Prerequisites

* .NET 10 or later.
* A running Infinispan server. You can start one with Docker:

[source,shell]
----
docker run -it -p 11222:11222 -e USER="admin" -e PASS="password" infinispan/server
----

== Running

Each tutorial is an independent project.
Run any tutorial from the `c#` directory:

[source,shell]
----
dotnet run --project cache
dotnet run --project counter
----

Override the server URI with the `INFINISPAN_URI` environment variable:

[source,shell]
----
INFINISPAN_URI="hotrod://user:pass@myserver:11222" dotnet run --project cache
----
