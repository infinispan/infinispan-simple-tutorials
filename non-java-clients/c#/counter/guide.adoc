This tutorial demonstrates how to use distributed counters with the .NET Hot Rod client, including strong counters with compare-and-swap and weak counters.

== Prerequisites

* A running Infinispan server.
* .NET 10 or later.

== Running the Example

[source,shell]
----
dotnet run --project counter
----

== Code Walkthrough

=== Strong Counter

Define a bounded, persistent strong counter and perform get, add, compare-and-swap, and reset operations.

[source,csharp]
----
var strong = counters.Counter("strong-counter");
await strong.AddAndGet(10);
await strong.CompareAndSwap(11, 50);
await strong.Reset();
----

=== Weak Counter

Weak counters support only add operations and are optimized for high-concurrency scenarios.

[source,csharp]
----
var weak = counters.Counter("weak-counter");
await weak.AddAndGet(5);
----
