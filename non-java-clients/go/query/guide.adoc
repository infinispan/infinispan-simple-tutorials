This tutorial demonstrates how to register Protobuf schemas and run Ickle queries with the Go Hot Rod client.

== Prerequisites

* A running Infinispan server.
* Go 1.25 or later.

== Running the Example

[source,shell]
----
go run ./query
----

== Code Walkthrough

=== Schema and Code Generation

The example uses a `proto/person.proto` file to generate a Go `Person` struct at build time with `protoc`.
The same schema — with Infinispan indexing annotations — is registered on the server.

[source,protobuf]
----
/* @Indexed */
message Person {
    /* @Keyword(projectable = true, sortable = true, normalizer = "lowercase") */
    string firstName = 1;
    /* @Keyword(projectable = true, sortable = true, normalizer = "lowercase") */
    string lastName = 2;
    /* @Basic(projectable = true, sortable = true) */
    int32 bornYear = 3;
    /* @Keyword(projectable = true, sortable = true, normalizer = "lowercase") */
    string bornIn = 4;
}
----

=== Creating a Typed Cache

`TypedCache` with `ProtoStreamMarshaller` handles serialization using the generated protobuf type.
No manual encoding or decoding is needed.

[source,go]
----
cache := hotrod.NewTypedCache[string, *pb.Person](client, "indexedPeopleCache").Build()
----

=== Query All (Typed)

[source,go]
----
results, err := cache.Query(ctx, "from tutorial.Person")
for _, p := range results {
    fmt.Printf("  %s %s\n", p.FirstName, p.LastName)
}
----

=== Query with Named Parameters

[source,go]
----
results, err := cache.Query(ctx, "from tutorial.Person p where p.lastName = :lastName",
    hotrod.WithQueryParam("lastName", "Granger"),
)
----

=== Query with Projections

[source,go]
----
result, err := cache.QueryProjection(ctx, "select p.firstName, p.lastName from tutorial.Person p where p.bornIn = 'London'")
for _, entry := range result.Entries {
    fmt.Printf("  %s %s\n", entry.Projections[0], entry.Projections[1])
}
----
