= Cache Encodings with the Go Client
:summary: Store data with different media types using text/plain and application/json encodings
:mode: remote
:topics: caching,encoding
:keywords: encoding,media-type,text,json,go,golang
:duration: 5
:source-dir: non-java-clients/go/encoding

TIP: The source code for this tutorial is available on link:https://github.com/infinispan/infinispan-simple-tutorials/tree/main/{source-dir}[GitHub].

This tutorial demonstrates how to use different cache encodings with the Go Hot Rod client.

== Prerequisites

* A running Infinispan server.
* Go 1.25 or later.

== Running the Example

[source,shell]
----
go run ./encoding
----

== Code Walkthrough

=== Text Cache

Create a cache with `text/plain` encoding by calling `WithEncoding` on the cache reference.

[source,go]
----
textCache := client.Cache("textCache").WithEncoding(hotrod.MediaTypeTextPlain)
textCache.Put(ctx, []byte("greeting"), []byte("Hello, Infinispan!"))
val, found, err := textCache.Get(ctx, []byte("greeting"))
----

=== JSON Cache

Create a cache with `application/json` encoding and store JSON documents.

[source,go]
----
jsonCache := client.Cache("jsonCache").WithEncoding(hotrod.MediaTypeJSON)
jsonCache.Put(ctx, []byte(`"name"`), []byte(`{"project": "infinispan"}`))
----

=== Separate Key and Value Encodings

When keys and values use different media types, use `WithKeyEncoding` and `WithValueEncoding`:

[source,go]
----
cache := client.Cache("mixed").
    WithKeyEncoding(hotrod.MediaTypeTextPlain).
    WithValueEncoding(hotrod.MediaTypeJSON)
----

== Expected Output

[source]
----
Caches ready.

== Cache with text/plain encoding ==

== Cache with application/json encoding ==

Caches removed.
----
